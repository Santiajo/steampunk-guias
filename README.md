# Guías · Steampunk Adventurers

Guías de uso de [steampunk-adventurers.netlify.app](https://steampunk-adventurers.netlify.app), publicadas con GitHub Pages.

| Guía | Carpeta | Para quién |
| --- | --- | --- |
| Guía del jugador | `jugador/` | Jugadores |
| Guía del DM y admin | `dm-admin/` | DMs y admins (no está enlazada desde la portada) |

Cada guía es HTML, CSS y JS sin dependencias ni build: `index.html`, `styles.css` y `app.js`. Las capturas de la guía del jugador están en `jugador/img/` y usan solo datos de prueba.
